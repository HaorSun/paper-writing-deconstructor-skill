# Paper Writing Deconstructor

Paper Writing Deconstructor 是一个用于提升论文写作能力的 Codex skill。它把学术论文视为一个有层级的论证系统，通过解构全文、章节、段落和句子，帮助用户从论文中学习可迁移的写作方法。

这个 skill 适合那些不只是想“读懂论文内容”，而是想进一步看懂论文如何被写成的用户：作者如何提出问题，如何组织章节，如何推进段落，如何使用句子完成论证、限定语气、建立贡献，并如何把这些写法转化为自己的写作资源。

## 核心工作流

默认工作流是：

```text
全文 -> 章节 -> 段落 -> 句子 -> 可迁移写作模式
```

### 1. 输入论文全文

当用户提供论文全文时，skill 会先建立整篇论文的结构地图。默认不会对全文做逐句分析。

它会识别：

- 研究问题
- 中心主张或研究目的
- 整体论证链条
- 各章节功能
- 关键论证节点
- 建议下钻分析的章节或段落

### 2. 输入论文章节

当用户提供某一章节，例如 Abstract、Introduction、Literature Review、Methods、Results、Discussion 或 Conclusion，skill 会分析该章节的内部结构。

它会识别：

- 该章节的典型学术功能
- 这篇论文实际采用的推进方式
- 各段落的功能
- 段落之间的衔接关系
- 值得精读的关键段落

### 3. 输入论文段落

当用户提供一个段落时，skill 会在一次回复中完成深度分析。

它包括：

- 段落功能
- 段落推进结构
- 句子四层解构
- 段内论证链条
- 可迁移段落模板
- 可复用句式模板
- 写作迁移建议

## 句子四层解构

在句子层面，skill 使用四层分析框架：

| 层级 | 核心问题 |
|---|---|
| 语义功能 | 这句话说了什么？ |
| 结构功能 | 这句话如何承接、开启、转折、限定或收束局部文本？ |
| 论证功能 | 这句话如何推进论文的主张、证据、研究空白、解释或贡献？ |
| 修辞/语气功能 | 这句话如何控制确定性、范围、强调、谨慎程度、权威性或读者预期？ |

## 示例 Prompt

```text
使用 $paper-writing-deconstructor 分析这篇论文全文，并建立整篇论文的结构地图。
```

```text
使用 $paper-writing-deconstructor 分析 Introduction 章节，识别其中的段落功能和推进结构。
```

```text
使用 $paper-writing-deconstructor 深度分析这个段落，包括段落结构、句子四层解构和可复用写作模板。
```

## 使用边界

这个 skill 不应：

- 编造论文内容、引用、方法、发现或作者意图
- 在用户没有明确要求时，把分析简化为摘要或翻译
- 鼓励直接复制原文句子
- 把不确定的章节位置说成确定判断

这个 skill 应该：

- 优先提供可迁移模板，而不是直接摘抄原句
- 解释一个写作动作为什么有效
- 帮助用户把论文写法迁移到自己的研究写作中
- 在全文分析阶段保持结构化，在选定段落后再进入句子级深度分析

## 适合的使用场景

- 通过高质量论文学习学术写作
- 分析论文 Abstract、Introduction、Discussion 等部分的写法
- 识别研究空白、贡献陈述、结果解释等写作动作
- 将论文中的句式和段落结构转化为自己的写作模板
- 对自己的论文草稿进行结构和功能层面的反馈
